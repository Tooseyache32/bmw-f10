ИНСТРУКЦИЯ ЗАПУСКА F10 ANATOMY

Папка проекта: C:\Users\Administrator\Desktop\site
Нужны Node.js 22 или новее и PostgreSQL 18.
Команды ниже предназначены для Git Bash.

1. ОТКРОЙТЕ ТЕРМИНАЛ В ПАПКЕ ПРОЕКТА

cd /c/Users/Administrator/Desktop/site

2. УСТАНОВИТЕ ЗАВИСИМОСТИ

npm install

Эта команда нужна при первом запуске или после изменения зависимостей.

3. ПРОВЕРЬТЕ POSTGRESQL ПРОЕКТА

"/c/Program Files/PostgreSQL/18/bin/pg_isready.exe" -h 127.0.0.1 -p 55432

Если написано «accepting connections», переходите к шагу 4.
Если написано «no response», запустите существующую базу проекта:

"/c/Program Files/PostgreSQL/18/bin/pg_ctl.exe" -D "C:/Users/Administrator/.zcode/workspace/draft-f6a021a9-4ed1-4be4-9770-2e549d330ba9/postgres-f10/data" -l "C:/Users/Administrator/.zcode/workspace/draft-f6a021a9-4ed1-4be4-9770-2e549d330ba9/postgres-f10/server.log" -o "-p 55432 -h 127.0.0.1" -w start

Используется отдельная база f10_anatomy на порту 55432.
Системную службу PostgreSQL на порту 5432 менять не нужно.
Параметры подключения уже записаны в локальном файле .env.
На другом компьютере необходимо отдельно установить PostgreSQL, создать базу и заполнить .env по образцу .env.example. Указанный выше путь относится только к этому компьютеру.

4. ПОДГОТОВЬТЕ ТАБЛИЦЫ И СПРАВОЧНИКИ

npm run db:migrate
npm run db:seed

Команды создают отсутствующие таблицы и заполняют каталог, не удаляя заявки.

5. ЗАПУСТИТЕ СЕРВЕР

npm start

Терминал должен оставаться открытым.
Для остановки нажмите Ctrl + C.
Для разработки с автоматическим перезапуском вместо npm start используйте:

npm run dev

6. ОТКРОЙТЕ САЙТ

Главная: http://localhost:3000/
Личный кабинет и вход: http://localhost:3000/account.html
Админ-панель: http://localhost:3000/admin.html
Заказ автомобиля: http://localhost:3000/order.html
Проверка сервера и базы: http://localhost:3000/api/ready

В ответе /api/ready должны быть: status «ready», database true, tables 9.
Открывайте именно localhost, а не 127.0.0.1: текущий APP_ORIGIN настроен на http://localhost:3000.

7. ВХОД АДМИНИСТРАТОРА

Откройте account.html и заполните форму «Вход».
Логин и пароль находятся в файле ДАННЫЕ_АДМИНА.local.txt рядом с этой инструкцией.
После входа нажмите «Админ-панель».
Регистрация обычного аккаунта не выдаёт права администратора.

ЕСЛИ ПОКАЗАНО «СЕРВЕР ПРОЕКТА НЕ ОТВЕЧАЕТ КАК API. ЗАПУСТИТЕ NPM START»

Запускайте npm start из основной папки site и открывайте http://localhost:3000/.
Не открывайте страницы через file://, Live Server или из папки site/index: в папке index находятся статические копии без JavaScript, серверные формы и вход в них не работают.

ЕСЛИ ПОРТ 3000 УЖЕ ЗАНЯТ

Проверьте http://localhost:3000/api/ready. Если сервер готов, второй запуск не нужен.
Если база недоступна, выполните шаг 3.

ЕСЛИ PG_CTL СООБЩАЕТ О СУЩЕСТВУЮЩЕМ POSTMASTER.PID

Не удаляйте этот файл и не завершайте процессы PostgreSQL наугад.
Убедитесь, что на порту 55432 нет работающего экземпляра проекта и что PID не относится к другой базе. Сам сервер проекта не запускает PostgreSQL автоматически.

ДАННЫЕ АДМИНИСТРАТОРА И .ENV НЕ ПУБЛИКОВАТЬ В GITHUB.
Это локальный учебный запуск. Перед публикацией нужны защищённые пароли БД, HTTPS и новые данные администратора.
