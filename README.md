# F10 Anatomy

Статический проект о BMW 5 серии F10. Семь связанных страниц, без сборщика и серверной части.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная, интро и интерактивный разбор автомобиля |
| `exterior.html` | Экстерьер и существующий пролёт вокруг автомобиля |
| `interior.html` | Салон и исходная 120-кадровая скролл-анимация |
| `engine.html` | Двигатель, трансмиссия, ходовая и характеристики |
| `tech.html` | Подвеска, ассистенты, мультимедиа и комфорт |
| `versions.html` | Сравнение 520d, 528i и 535i |
| `contact.html` | Локальная подготовка запроса, копирование и скачивание |

Четыре новые страницы используют общие `assets/css/chapters.css` и `assets/js/chapters.js`: переключение темы, Lenis, появления блоков, подвал и обработчики интерактивных элементов. Главная, экстерьер и салон сохраняют собственные скрипты. Общий скрипт новых страниц к ним не подключён.

На всех семи страницах установлена одинаковая статичная шапка по образцу главной: F10 · Anatomy, Dingolfing, семь ссылок на страницы и действия в скобках. Общие стили — `assets/css/site-header.css`, подключаются после стилей страницы. На узких экранах навигация доступна через нативное меню «Страницы»; ссылки работают и без JavaScript. Активная страница отмечена `aria-current="page"`. Переключатели тем сохраняют прежние обработчики. В экстерьере исходная секционная навигация сохранена скрытой для совместимости существующих анимаций, а видимые ссылки используют отдельные классы.

## Запуск

Для корректной работы изображений, видео и Canvas предпочтителен локальный HTTP-сервер. Из папки проекта:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000/index.html`.

Lenis 1.1.13 на новых страницах загружается с jsDelivr. При недоступности библиотеки остаётся нативная прокрутка. Существующие страницы дополнительно используют GSAP/ScrollTrigger и внешние шрифты. Это не полностью офлайн-проект.

## Характеристики

Единый срез: европейский седан без xDrive, задний привод, 8-ступенчатая АКПП Steptronic; характеристики действуют с июля 2013. Расход — официальный комбинированный цикл EU для стандартных колёс 8J × 17 с шинами 225/55 R17, не обещание расхода в реальной поездке. Мощность в метрических лошадиных силах PS.

Данные хранятся в `assets/js/specs.js`. В `versions.html` есть статическая таблица для чтения без JavaScript. При изменении исходных данных необходимо согласованно обновить и её.

Официальный релиз BMW Group от 26 июня 2013:
https://newsroom.bmwgroup.com/global/specifications-of-the-bmw-5-series-sedan-valid-from-july-2013/

Ссылки на технические PDF доступны на обеих страницах. Значения для АКПП взяты из скобок в оригинальных листах. Коды двигателя в этих документах отсутствуют, поэтому в наборе данных оставлены `null`.

## Контакты и форма

Проект не содержит реальных реквизитов владельца. В `assets/js/site-settings.js` можно заполнить:

- `email` — реальный email;
- `telegram` — полную HTTPS-ссылку;
- `whatsapp` — полную HTTPS-ссылку;
- `address` — реальный адрес.

Заполненные каналы появятся на странице контактов. Пустые каналы не создают ложных ссылок и карты.

**Форма не отправляет сообщения.** Она проверяет обязательные поля, создаёт локальный текст, позволяет скопировать его или скачать `.txt`. Данные не записываются в хранилище сайта и не отправляются в сеть. Автозаполнение браузера может работать по его собственным настройкам.

`endpoint` в настройках зарезервирован и не подключён: запись URL не включает серверную отправку. Для настоящей заявки отдельно нужны backend, проверка данных, защита от спама и согласованные условия обработки персональных данных. До их подключения не следует менять текст кнопки на «Отправить» или показывать подтверждение доставки.

## Изображения и анимации

Фотографии обновлены на **всех семи страницах**. В экстерьере заменены 17 независимых фотоблоков и синхронные превью; в интерьере — все три карточки после пролёта; на главной добавлен видимый фотоблок, потому что прежнее статичное изображение было скрыто. Страницы двигателя, технологий, модификаций и контактов используют отдельные снимки. Новая фотосерия находится в `assets/img/f10-page-refresh/`, часть ранее найденных оригиналов — в `assets/img/f10-unique-photos/`.

Точные назначения — `assets/img/f10-page-refresh/page-photo-map.json`, авторы, лицензии и ссылки на оригиналы — на странице `assets/img/f10-page-refresh/photo-credits.html` и в `sources.json`/`ATTRIBUTION.md` папок `exterior` и `interior`. Все файлы — реальные JPEG с уменьшением до 1280–1920 px без увеличения оригиналов; основная серия — 1600–1920 px. Для некоторых блоков использован общий вид кузова, а не неподтверждённый крупный план детали. Салон M5 F10 подписан как отдельная спортивная версия и не выдаётся за стандартную комплектацию 535i.

Повторное использование одного изображения для подсветки фары или предпросмотра той же фотографии не считается отдельным фотоблоком и сохранено. Снимки показывают конкретные автомобили, не обязательное оснащение всех модификаций. Кадры скролл-анимаций и видео не заменялись.

Исходные `frames_interior/i_0001.webp`–`i_0120.webp` и `interior.mp4` сохранены. Скрипты старых страниц не переписывались при добавлении меню семи глав. Файлы в `assets/interior-scroll-lite/`, созданные во время предыдущей правки, не подключены к новым страницам и не заменяют исходную последовательность салона.

## Дизайн

Референсы направления: автомобильный сторителлинг Spyker Cars и типографические/сеточные решения Grids (Obys) из Awwwards. Используются собственные композиции: тёмный технический раздел, спокойный светлый технологический, каталог сравнения и редакционная страница запроса.

Новые страницы поддерживают светлую/тёмную тему, клавиатурную навигацию и `prefers-reduced-motion`. Выбранная тема сохраняется под ключом `f10-interior-theme`.

Браузерные и автоматические проверки готового сайта не выполнялись по просьбе владельца; просмотр Awwwards использовался только для референсов.
