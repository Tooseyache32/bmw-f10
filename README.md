# BMW 5 Series (F10) — Interactive Anatomy Showcase

Одностраничная интерактивная презентация BMW 5 Series (F10) в стиле премиального
автомобильного промо-сайта.

## Возможности

- 🎬 Кинематографичное видео-интро с титрами и flash-переходом
- 🪐 Hero-сцена: 3D-планета с орбитальным облётом BMW F10 (seamless loop, 4K)
- 🔧 Интерактивный разбор кузова на canvas — 120 покадровых WebP-кадров,
  привязанных к наведению курсора, с hotspot-точками и выносками
- 🎨 Пастельные bento-карточки ключевых особенностей (Playfair Display)
- 📊 Секция характеристик с анимированными цифрами
- 🖼️ Галерея на bento-сетке
- 📱 Адаптивная вёрстка (HTML5 Canvas / CSS / ванильный JS, без зависимостей)

## Запуск

Сайт статический — достаточно открыть `index.html` в браузере,
либо поднять любой локальный сервер:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Структура

```
├── index.html          # единственная страница (вся вёрстка, стили и логика)
├── intro.mp4           # интро-видео загрузочного экрана
├── frames/             # 120 webp-кадров покадровой разборки
└── assets/
    ├── img/            # стационарные изображения
    └── video/          # видео: орбита планеты, разборка, инспекция
```
